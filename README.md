# SleepcareAI · Colab notebooks

Folder [`notebooks/`](notebooks/README.md) chứa notebook DINOv3 + SLARDA, script tạo gói Colab và hướng dẫn chi tiết. Mở README của folder để xem mục **“Chỉ chỗ đã update”**.

Repository này chỉ lưu phần có thể chia sẻ qua Git. Checkpoint DINOv3, dữ liệu Sleep-EDF, ZIP được tạo và folder upload Google Drive được giữ cục bộ. Để chạy các script tạo gói, cần đặt folder `notebooks/` trong project `SLARDASSC` cùng `Autorgressive_Adaptation/` và `sleep_edf_tools/`, rồi chuẩn bị dữ liệu/checkpoint theo hướng dẫn trong [`notebooks/README.md`](notebooks/README.md).
